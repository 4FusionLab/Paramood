# Руководство пользователя Paramood

[English](USER_GUIDE.md) · [Обзор и установка](../README.ru.md)

Руководство описывает текущий исходный код. При сравнении доступных функций сверяйся с примечаниями к установленному релизу.

## Работа в палитре

Открой Paramood в активной модели Fusion. По умолчанию выбран **Hybrid**: дерево параметров доступно в списке, поле вычислений и присваиваний закреплено снизу. Результаты, история и предпросмотр появляются поверх списка; панель можно закрыть, чтобы снова видеть список. Кнопки **Calculator** и **Parameter list** переключают виды, сохраняя общий ввод.

Введи `2+3` для вычисления без записи в модель. Ввод `width=30mm; height=width/2` открывает предпросмотр пакета. Проверь имена, выражения, единицы и значения, затем нажми **Apply parameters**. Ссылка на `width` сохраняется в Fusion как зависимость.

Подчёркивания образуют виртуальные группы: `box_wall_thickness` отображается как `box.wall.thickness`. При вводе доступны обе записи. Размеры `dN` находятся в **Model parameters**. Справочные размеры эскиза доступны только для чтения. Нажми редактируемое значение, чтобы изменить его; **Enter** проверяет и применяет, **Escape** отменяет. Переименование доступного параметра меняет ссылки, сохраняя одноимённые слова внутри строковых литералов.

IntelliSense предлагает модельные размеры вроде `d1`, только когда текущий ввод — ровно `d` или `D`, по обе стороны присваивания. При `de`, `d1` и числах эти подсказки скрыты; существующие имена размеров по-прежнему доступны в выражениях.

В строке редактирования числового параметра можно ввести `+=5`, `-=5`, `*=2` или `/=2`, чтобы изменить существующее выражение. При сложении и вычитании число без единицы использует единицу параметра, при умножении и делении — безразмерное значение. Зависимости исходной формулы сохраняются.

Селектор рядом с названием меняет единицы отображения модели на `mm`, `cm`, `m`, `in` или `ft`, сохраняя физические размеры. При числовом редактировании в строке списка и присваивании в поиске варианта число без единицы использует единицу этого параметра. Для передачи примеров удобнее указывать единицы явно.

Иконка возле результата калькулятора копирует значение с единицами. **Copy expression** копирует введённое выражение. Успешное уведомление исчезает через 3,5 секунды; ошибка остаётся до закрытия.

## Создание варианта

Вариант хранит выражения и значения выбранных существующих редактируемых параметров: пользовательских, модельных и строковых. Он не является снимком всей модели и не управляет подавлением операций.

1. В меню вариантов в шапке выбери **Create variant**.
2. Введи уникальное имя, например `Compact`.
3. Отметь параметры, выражения которых должны войти в вариант. Группы совпадают с основным деревом; поиск поддерживает IntelliSense. Кнопка с количеством выбранных оставляет в списке только участников.
4. Измени их выражения. Присваивание в поиске, например `box.width=30`, выбирает существующий `box_width` и задаёт выражение в черновике. CAD-параметр при этом не создаётся. **Enter** очищает поиск.
5. Нажми **Save & apply**: вариант сохраняется, а выражения применяются к модели. Нужен хотя бы один участник.

Для применения выбери имя варианта в шапке. Остальные параметры сохраняют текущее состояние; для прямо сравнимых конфигураций используй одинаковый набор участников. Искусственного ограничения количества вариантов нет, но размер атрибутов Fusion ограничен. **Find variant** появляется при количестве больше пяти; длинный список прокручивается внутри меню.

## Изменение, выход и удаление

Когда вариант активен, успешное изменение параметров через Paramood обновляет его. Изменённые параметры, ещё не входящие в набор, добавляются автоматически. Это относится и к строкам.

Выбери **Free** перед правками, которые не должны перезаписывать сохранённые варианты. Текущие значения модели останутся. Внешние изменения через Fusion, после которых активный вариант перестаёт совпадать с моделью, тоже переводят Paramood в Free; варианты не перезаписываются.

Карандаш рядом с вариантом открывает изменение имени, участников и выражений. Исключение участника сохраняет CAD-параметр. Удаление варианта тоже сохраняет параметры и текущие значения модели. Отсутствующий параметр помечается **Needs attention**; новый одноимённый параметр не подставляется вместо исходного автоматически.

Если модель изменилась при открытом редакторе, устаревшее сохранение отклоняется. Проверь ошибку и используй **Reload from model**, чтобы сбросить черновик к актуальному состоянию перед новой попыткой.

## Сохранение и передача F3D

Варианты записаны в атрибутах модели Fusion. Обычное сохранение или экспорт F3D сохраняет их; Paramood сам не запускает облачное сохранение. Передай F3D и открой его в Fusion с включённым Paramood для чтения вариантов.

При повторном открытии Paramood сравнивает значения участников с моделью. Числа сравниваются с допуском во внутренних единицах Fusion; строки — точно, включая пробелы и пустоту. Полное совпадение выбирает вариант. Если совпало несколько, выбирается первый созданный; если ни одного — **Free**. Явный выбор Free до закрытия не задаёт постоянный сброс выбора при следующем открытии.

Допустимое выражение может привести к ошибке операции в timeline Fusion. Ошибки и предупреждения timeline не откатывают применённый вариант. Проверяй геометрию и выбирай исправную конфигурацию перед передачей модели. Ошибки выражений, устаревшие запросы и неполная запись сообщаются отдельно.

## Строковые параметры

Литерал в кавычках автоматически создаёт текст:

```text
caption='Корпус'
```

Допустимо и `caption="Корпус"`. Список показывает вычисленный текст, а редактор — исходное выражение. При изменении формулы ссылки сохраняются:

```text
label=caption+' / Compact'
```

Для существующего параметра длины `width` можно задать условный текст:

```text
label=if(width<20 mm; 'Short'; 'Long')
```

Поддерживаются литералы, ссылки на строки, конкатенация `+` и `if` с одним сравнением совместимых значений. Числовые и строковые операнды нельзя смешивать, тип существующего параметра менять нельзя.

| Ввод | Содержимое |
| --- | --- |
| `caption=''` | Пустая строка |
| `caption='a=b;c'` | Знак равенства и точка с запятой внутри текста |
| `caption='Bird\'s feeder'` | Апостроф |
| `caption='Line 1\nLine 2'` | Перевод строки |
| `caption='C:\\Example'` | Обратный слеш |

Оба вида кавычек переводятся в синтаксис Fusion с одинарными кавычками. Поддерживаются escapes `\'`, `\\`, `\n`, `\r`, `\t`; двойную кавычку внутри одинарных можно вводить без экранирования. Неизвестные escapes и соседние литералы вида `'a''b'` отклоняются; для соединения используй `'a'+'b'`.

Результат строки ограничен 65 536 символами, суммарный вычисленный текст планируемого пакета — 262 144 символами. Неподдерживаемое выражение, нужное для запрошенного изменения, отклоняется; посторонняя строковая формула сама по себе не блокирует числовые правки. Проверка зависимостей по-прежнему охватывает полный граф модели.

## Ограничения

- Изменяются параметры активной модели; внешне связанные компоненты не редактируются.
- Fusion может запретить изменение или удаление. Справочные размеры остаются только для чтения.
- Обновление существующих параметров поддерживает прямое применение во время активной команды; создание и связывание нового параметра может потребовать завершить команду или эскиз.
- Автоматическая очистка неиспользуемых параметров недоступна.
- Автотесты и проверки на временной модели Fusion отличаются от полной приёмки установленной палитры. Нативная проверка Windows не завершена; фактический объём проверки указан в примечаниях к релизу.
