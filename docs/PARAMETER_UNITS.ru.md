# Единицы существующего параметра

[English](PARAMETER_UNITS.md)

## Подтверждённое ограничение API

Запрошена смена назначенных native единиц/типа отдельного параметра, а не единиц отображения
документа. На 11 ноября 2026 года Autodesk документирует
[`UserParameter.unit`](https://help.autodesk.com/cloudhelp/ENU/Fusion-360-API/files/fusion_UserParameter_unit.htm)
и [`valueType`](https://help.autodesk.com/cloudhelp/ENU/Fusion-360-API/files/fusion_UserParameter_valueType.htm)
как свойства только для чтения. В установленном Python API Fusion 2706.1.17 у обоих свойств
также нет сеттеров. Для model parameters действует то же ограничение базового `Parameter`.

Поэтому Paramood **не предлагает** изменение назначенных единиц/типа существующего параметра,
включая неиспользуемые. Единицы в дереве — обычный текст без взаимодействия.
Text и безразмерные параметры обозначены `Text` и `—`.
Это ограничение API, а не заключение о том, что свободный параметр используется.

## Матрица поддержки

Для всех семейств ниже результат одинаков: **API не позволяет сменить назначенные единицы/тип
на месте**. Матрица охватывает семейства из
[справочника единиц Autodesk](https://help.autodesk.com/cloudhelp/ENU/Fusion-Model/files/DSN-REF-PARAMETERS-UNITS.htm)
и существующего каталога единиц Fusion; область не ограничена длиной и углом.

| Семейства | Примеры | Изменение существующего параметра |
| --- | --- | --- |
| Длина; угол | mm, in; deg, rad | Недоступно |
| Площадь; объём; время | cm^2; l; s | Недоступно |
| Угловая скорость; скорость; расход | rpm; m/s; cfm | Недоступно |
| Масса; сила; энергия; мощность; давление; вязкость | kg; N; J; W; Pa; poise | Недоступно |
| Температура; количество вещества | K; mole | Недоступно |
| Ток; заряд; ёмкость; проводимость; сопротивление; ЭДС; индуктивность | A; coulomb; farad; S; ohm; V; H | Недоступно |
| Магнитный поток; магнитное поле; намагничивающее поле | Wb; T; oersted | Недоступно |
| Сила света; световой поток; освещённость; телесный угол | cd; lm; lx; sr | Недоступно |
| Частота; валюта; штуки | Hz; dol; pcs | Недоступно |
| Другие допустимые составные размерности | kg*m/s^2 | Недоступно |
| Безразмерный | пустая строка единиц | Недоступно |
| Текст; число ↔ текст | Text | Недоступно |

API принимает единицы при **создании** нового параметра через
[`UserParameters.add`](https://help.autodesk.com/cloudhelp/ENU/Fusion-360-API/files/fusion_UserParameters_add.htm).
Создание не заменяет изменение существующего параметра с сохранением его идентичности.

## Проверенные альтернативы

- [`expression`](https://help.autodesk.com/cloudhelp/ENU/Fusion-360-API/files/fusion_UserParameter_expression.htm)
  принимает совместимые явные единицы. Например, параметр в mm может содержать `1 in`.
  Это редактирование формулы/значения, а не назначенных единиц. Подмена формулы численным
  результатом пересчёта потеряла бы зависимости и не выполняется автоматически.
- [`UnitsManager.convert`](https://help.autodesk.com/cloudhelp/ENU/Fusion-360-API/files/core_UnitsManager_convert.htm)
  и `formatValue` пересчитывают или форматируют совместимые значения без изменения метаданных.
  Локальная настройка отображения палитры не выполняет требование о native единицах.
- `FusionUnitsManager.distanceDisplayUnits` меняет настройку длины всего Design,
  а не тип отдельного параметра. Это отдельный переключатель возле имени документа.
- Удаление и пересоздание не сохраняет entity identity и угрожает формулам, геометрии,
  комментариям, избранному и сохранённым вариантам. Paramood этого не делает.
- Для ручного изменения native единиц доступен диалог Fusion **Change Parameters**
  с собственными ограничениями Fusion. Paramood не автоматизирует его и не утверждает,
  что он проверяет сохранённые варианты Paramood при смене размерности.

Будущей реализации сначала нужен поддерживаемый API. Перед записью необходимы повторные проверки
документа, snapshot, реальных зависимостей параметров/геометрии и всех сохранённых формул вариантов.
Неполные сведения о зависимостях не позволяют считать параметр свободным. Используемые параметры
могут менять единицы только в своей размерности; смена размерности требует явного предпросмотра
выражения/значения и сохранения identity и метаданных. Сейчас эти операции недоступны, а не имитируются.
