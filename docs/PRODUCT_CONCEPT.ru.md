# Paramood — продуктовая концепция

> **Статус: проектирование.** Этот документ описывает запланированное поведение, а не реализованные и проверенные в Autodesk Fusion функции.

## Назначение

Paramood помогает работать со **смыслом размеров**: именами, выражениями, вычисляемыми значениями и зависимостями. Инструмент дополняет штатные параметры Fusion, не заменяя параметрическую модель.

## Основные сценарии (в планах)

### 1. Quick Parameters

Компактный редактор принимает несколько именованных выражений, например:

~~~text
w=15; h=10; l=h/2
~~~

Нужны автодополнение, подсветка синтаксиса, ошибки прямо под вводом и предпросмотр результата **до применения**. Выражения со ссылками на другие параметры должны оставаться выражениями, а не заменяться вычисленными числами.

### 2. Реактивный калькулятор

При вводе формул интерфейс распознаёт существующие параметры, проверяет выражения и показывает вычисленные значения там, где это допускает Fusion API. Неизвестные имена, дубликаты, ошибки синтаксиса, несовместимые единицы и циклические зависимости должны отображаться явно.

### 3. Менеджер параметров

Отдельный HTML-интерфейс: поиск, фильтры и визуальная сортировка параметров. Сортировка действует **только в интерфейсе Paramood**: Fusion API не предоставляет универсального изменения порядка строк в штатной таблице параметров.

### 4. Безопасная очистка

Поиск неиспользуемых параметров должен учитывать граф зависимостей и ссылки в модели. Удаление — только **по явному выбору пользователя**, с проверкой зависимостей и безопасной обработкой ошибок. Никакого скрытого массового удаления.

### 5. Quick Tools

Компактная HTML Palette, при необходимости постоянно доступная для работы. Она должна быть **отделена от штатной панели Comments в Fusion**; не предполагаем возможности встроить туда собственный интерфейс.

## Технический подход (предварительный)

- **Интеграция с Fusion:** Python add-in через Fusion API.
- **Интерфейс:** HTML Palette; текущий ориентир — TypeScript, Preact и CodeMirror.
- **Связь:** проверяемые JSON-сообщения между HTML и Python.
- **Изменение параметров:** обновляем `expression`, а не подменяем вычисленное `value`.
- **Безопасность:** предпросмотр, валидация и понятные ошибки до записывающих операций.
- **Совместимость:** проверяем доступность API внутри Fusion, прежде чем обещать поддержку платформ и выпуск. Критические сценарии не должны зависеть от нестабильных Preview API.

## Принципы UX

1. **Быстро:** частые изменения за минимум действий.
2. **Понятно:** показываем имена, формулы и связи, а не только числа.
3. **Безопасно:** объясняем последствия изменения до применения.
4. **Компактно:** удобная клавиатурная работа, светлая и тёмная темы.
5. **Точно:** не обещаем пользователю того, чего не позволяет Fusion API.
