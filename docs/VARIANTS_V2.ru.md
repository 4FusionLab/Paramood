# Общая таблица вариантов — проверочная сборка 2.0

[English version](VARIANTS_V2.md)

Ветка ожидает личного просмотра владельцем. До явного разрешения на релиз нельзя публиковать
сборку, отправлять её в main, создавать теги или запускать автоматический выпуск.
`GitVersion.yml` задаёт следующую мажорную версию 2.0.0, но сам ничего не публикует.

## Работа с таблицей

Переключатель Free/варианты в шапке сохраняет прежний способ работы. Карандаш или Create variant
открывает общую таблицу модели. Configure выбирает единый упорядоченный набор редактируемых
пользовательских, модельных и строковых параметров, а также поддерживаемых параметрических фич
timeline. Каждый вариант имеет ячейку для каждого участника. Параметры вне набора глобальны:
их изменение не включает их в варианты даже при активном варианте. Иконка таблицы в общем списке
отмечает управляемые параметры; подсказка **Controlled by variants** доступна и в режиме Free.

- При любой ширине палитры варианты — строки, параметры и фичи — столбцы.
- Все заголовки горизонтальные и переносятся по словам; слишком длинное отдельное слово
  разбивается только при необходимости. Горизонтальная прокрутка появляется лишь при нехватке места для читаемых значений.
- Ручки позволяют перетаскивать оба порядка. Они сохраняются в модели. Alt + стрелки на ручке служат клавиатурной альтернативой. Внешние данные перетаскивания
  не создают новые элементы и не подменяют идентичность объектов.
- Клик по значению открывает редактирование выражения с выделением содержимого. Enter завершает
  редактирование ячейки; Tab переходит дальше. Эти действия ничего не записывают в Fusion.
- Галочка фичи означает **Enabled**, снятая галочка — **Suppressed**.
- Новый вариант получает текущие значения модели для выбранного набора. Duplicate копирует строку.
  Добавление участника заполняет его ячейки во всех вариантах текущим состоянием модели.
- Клик по имени переименовывает вариант на месте. Кнопки Duplicate и Delete расположены рядом;
  удаление требует подтверждения в той же строке. Последняя строка — **+ Add variant**. Исключение участника или удаление варианта не удаляет
  соответствующий CAD-параметр или фичу.

Все изменения таблицы остаются черновиком до **Save**. При закрытии изменённой таблицы требуется
подтвердить отбрасывание черновика. Save сначала проверяет все строки. Если изменились ячейки
активного варианта, Save также применяет именно его к модели. Остальные строки сохраняются без
переключения. В Free ничего не применяется. При удалении активной строки геометрия сохраняется,
а выбор становится Free. Если после применения не удалось записать таблицу, выполняется попытка
восстановить выражения и suppression; неудачное восстановление сообщается как частичная операция.

Внешнее изменение Fusion не стирает черновик: Save блокируется, а замена введённых данных при
Reload from model требует подтверждения. Запросы содержат идентичность документа, хранилища
и снимка модели. Фронтенд не хранит живые CAD-объекты.

**Pick from timeline** в Configure включает выбор только для черновика. Кликни поддерживаемую
фичу на таймлайне Fusion: она станет столбцом с текущим состоянием Enabled во всех вариантах.
Done picking завершает режим. Повторный выбор не дублирует столбец. Требуется обычный Select;
другие команды не прерываются и не завершаются автоматически. События содержат идентичность
документа и не могут добавить участника в чужой черновик. Поиск по списку остаётся альтернативой.

## Хранение и ограничения

Используется только формат 2 в атрибуте Design `4FusionLab.Paramood / variants.v2`. Прежний атрибут
`variants.v1` не читается, не мигрируется и не удаляется. Геометрия примеров 1.x сохраняется,
но старые варианты в 2.0 не отображаются: их нужно создать заново в таблице.
Configuration API Autodesk и преобразование модели в Configured Design не используются.

Атрибут содержит общий порядок колонок и порядок вариантов. Ячейки каждой строки обязаны точно
соответствовать выбранным параметрам и фичам. Объекты разрешаются через Design.findEntityByToken;
при проверке дубликатов сравниваются объекты, а не строки токенов. Новый одноимённый объект не
подставляется вместо удалённого. До записи проверяются имена, типы ячеек, выражения, зависимости,
идентичность запроса и ограничение 2 MiB.

Обход timeline учитывает группы и включает валидные параметрические Feature. Прямые операции,
эскизы, группы целиком и элементы без публичного Feature не выбираются. Отдельные фичи внутри
групп поддерживаются. Включение идёт в порядке timeline, подавление — в обратном, независимо
от порядка таблицы. Предупреждения и ошибки последующих операций отделены от ошибок записи.

Сборка заменяет согласованные сценарии параметров и suppression. Полного соответствия Fusion
Configurations пока нет: видимость, материалы, внешний вид, свойства деталей, тематические
подтаблицы, правила, вставки конфигураций и связанные дальнейшие сценарии не реализованы.

## Проверки

- Офлайн: формат, порядок, проверка всех строк, границы общего набора, Save активной строки,
  восстановление при ошибке записи, устаревшие запросы, идентичность фич и обход свёрнутых групп.
- Фронтенд: общий набор, смысл Enabled, сохранность и отмена черновика, оба порядка, отклонение
  внешнего drop, действия переключателя и метки параметров.
- Браузер: настоящий фронтенд с имитацией моста в `frontend/variants-preview.html`, единая ориентация при любой ширине,
  переносы заголовков, позднее появление скролла, перетаскивание и сохранение порядка ячеек.
- Fusion на macOS, 2706.1.17: `tests/fusion_variants_v2_smoke.py` прошёл на временной модели.
  Save в Free не применял значения; extrusion подавлялся и включался; проверены реальные высоты
  35 и 45 мм; Save применял только активную строку; внешний параметр оставался глобальным;
  состояние содержало метки управляемых параметров; получены нативный выбор фичи и событие выбора; старый атрибут не менялся; Free сохранял
  геометрию. Отдельно выполнен настоящий клик мышью по extrusion на таймлайне временной модели;
  подтверждены выбранная ExtrudeFeature и событие activeSelectionChanged. Временные документы
  закрыты без сохранения, исходный документ восстановлен.
- Проверка исходного адаптера не подтверждает UI установленной палитры, F3D round-trip, все типы
  фич, Windows или личную приёмку владельцем. Разрешения на релиз нет.

Первичные источники API перечислены в [английской версии](VARIANTS_V2.md).
