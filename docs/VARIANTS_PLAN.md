Ветка: `codex/variants`, основание: `codex/next-release`.

1. Добавить версионированное хранение вариантов в атрибутах Design, отдельно от CAD-параметров.
2. Согласовать мост: состояние, сохранение с применением, переключение, свободный режим, удаление.
3. Встроить меню вариантов в шапку; редактор с поиском, выбором параметров и выражениями.
4. Проверить контракты, устаревшие запросы, повреждённые данные, совпадения и автозапись.
5. Выполнить проверки проекта, браузерную проверку и CAD-приёмку на временной модели.

## Поведение

- `Free` не меняет параметры и отключает автозапись в вариант до следующего выбора.
- Сохранение создаёт/обновляет вариант и применяет его выражения. Нужен хотя бы один параметр.
- Вариант хранит имя, стабильный ID, токены параметров, выражения, единицы и числовые значения.
- При первом чтении документа выбирается первый полностью совпавший вариант; при нескольких
  совпадениях текущий выбор сохраняется, а при повторном открытии используется порядок создания.
- Совпадение проверяется по значениям в единицах Fusion с числовым допуском, а не по форматированию.
- Успешные изменения параметров через Paramood обновляют активный вариант и добавляют изменённые
  параметры. Изменение через другие инструменты Fusion определяется при обновлении состояния:
  несовпадение переводит в `Free`, не перезаписывая сохранённые варианты.
- Удаление из варианта не удаляет параметр модели. Удалённые из модели параметры отмечаются
  отсутствующими; их нельзя случайно заменить новым параметром с тем же именем.
- Ошибки timeline не являются условием отказа или отката. Ошибки выражений, записи и устаревшие
  снимки обрабатываются отдельно. В активной команде Fusion применяется прямой пакетный API.
- Варианты входят в обычное сохранение файла модели; облачное сохранение автоматически не вызывается.

## Проверенные API

Context7 не нашёл документацию атрибутов в индексе Autodesk; использованы первичные источники:

- [Design.attributes](https://help.autodesk.com/cloudhelp/ENU/Fusion-360-API/files/fusion_Design_attributes.htm)
- [Attributes.itemByName](https://help.autodesk.com/cloudhelp/ENU/Fusion-360-API/files/core_Attributes_itemByName.htm)
- [Attributes.add](https://help.autodesk.com/cloudhelp/ENU/Fusion-360-API/files/core_Attributes_add.htm): создание/обновление, предел 2 MiB на атрибут.
- [Design.findEntityByToken](https://help.autodesk.com/cloudhelp/ENU/Fusion-360-API/files/fusion_Design_findEntityByToken.htm)
- [Design.modifyParameters](https://help.autodesk.com/cloudhelp/ENU/Fusion-360-API/files/fusion_Design_modifyParameters.htm): пакет всех изменений либо ни одного, только локальные параметры.

Количество вариантов программно не ограничивается; действуют ограничения размера атрибутов Fusion.

## Уточнения интерфейса и проверка

- Иерархия вынесена в общий `parameter-tree.ts`; основной список и редактор вариантов используют
  один алгоритм группировки и сортировки. Стандартные `dN` остаются в разделе Model parameters.
- Поле поиска параметров использует существующий ExpressionEditor/CodeMirror с IntelliSense,
  однострочным вводом и немедленным присваиванием в черновик. Dotted-ссылки преобразует общий
  ParameterIndex; числовой литерал использует единицы целевого параметра. Enter очищает поиск.
- Поиск вариантов виден только начиная с шестого варианта. Меню вычисляет положение относительно
  кнопки, ограничивает ширину и высоту окном; прокрутка длинного списка остаётся внутри меню.
- Общая кнопка Refresh удалена. При конфликте редактор сохраняет черновик, перечитывает состояние
  и предлагает `Reload from model` для явного сброса устаревших настроек.
- Ручное ревью границ: в мосте разрешены только четыре новые операции; каждая запись проверяет
  documentId, токен снимка модели и версию хранилища; токены параметров разрешаются в реальные
  объекты текущего Design. Входные данные не исполняются как JavaScript/Python. Повреждённые и
  будущие форматы не затираются. При прямом обновлении без транзакции ошибка автосохранения
  компенсируется восстановлением прежних выражений; для смешанного пакета с созданием
  возвращается явная ошибка частичного результата.

## Гибридный вид, единицы и буфер обмена

Дополнительные запросы реализованы в той же ветке: гибридный вид по умолчанию, панель результатов
над закреплённым полем, переключатель единиц около названия, автозакрытие успешных уведомлений через
3,5 секунды. Дублирующая кнопка Copy number удалена; иконка рядом с результатом копирует значение с
единицами, Copy expression копирует введённое выражение.

Проверка копирования: в чистой вкладке исходная Clipboard API действительно записала `5`, и Meta+V
вставил `5` обратно в редактор. Универсальный отказ в браузере не воспроизведён. Отдельный тест
реального App воспроизвёл отсутствие записи при недоступной navigator.clipboard; до исправления
ожидание `5` получало пустую строку. Добавлен ограниченный fallback через временное textarea и
execCommand('copy'), с проверкой результата, восстановлением фокуса и выделения и удалением
временного поля. Отказы обоих путей не дают ложного сообщения об успехе. Windows WebView и нативное
копирование внутри установленной палитры Fusion остаются непроверенными.

Общий ParameterIndex из `src/intellisense.ts` теперь импортируется распространяемым фронтендом.
Файл добавлен в `.github/release-paths.txt` и контрактный тест; прежний комментарий о том, что весь
`src/` не входит в runtime, обновлён. Workflow и правила выпуска тегов не менялись.
