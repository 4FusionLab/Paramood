## Paramood 1.6.1

### Native expression parity

- Delegate original numeric formulas to Fusion during Preview and Calculate. Keep pre-write native validation and graph/document/snapshot checks.
- Accept `random()` in Preview, Apply, inline edits, dependencies, and variants. Label sampled values with `≈`, preserve the source formula on Apply, and read actual values back from Fusion.
- Avoid false stale-preview and result-mismatch failures after random recompute. Preserve detection of changed formulas, units, documents, and deterministic values.
- Support all 96 official unit abbreviations, canonical aliases, physical and compound dimensions, affine temperatures, native unit symbols, and valid fractional powers. Preserve target units for updates and relative operations.
- Follow native lazy conditional evaluation, implicit unit promotion, and dimensioned rounding/sign semantics. Remove the runtime dimension allowlist and nondeterministic-expression refusal.
- Add a reproducible native Fusion acceptance script and expand automated unit, snapshot, variant, lexer, and preview tests.

### Verification

Native macOS Fusion 2706.1.17: all 96 units, 26 functions, and 25 additional scenarios passed. Random expressions and variants survived recompute and F3D export/reopen; deterministic external changes still invalidated previews. Original user documents were preserved. Native Palette checks and offline/CI evidence are recorded in the [acceptance report](https://github.com/4FusionLab/Paramood/blob/main/docs/EXPRESSION_ACCEPTANCE.md).

Native Windows, cloud Save, and full add-in stop/restart were not tested. The previously reported restart crash is outside this fix. The [expression reference](https://github.com/4FusionLab/Paramood/blob/main/docs/EXPRESSION_REFERENCE.md) describes the new native evaluation behavior.
