## Paramood 2.2.0

[Русский](https://github.com/4FusionLab/Paramood/blob/v2.2.0/docs/releases/2.2.0.ru.md)

### Search and organization

- Search the parameter tree by name, full native/virtual path, expression or comment, including Cyrillic. Search starts collapsed; closing it restores group expansion, scroll and trigger focus. Existing inline drafts remain isolated from search input.
- Rename or drag an entire virtual group, including its own value and hidden descendants. Dependencies and saved variant references follow the complete subtree. Conflicts and invalid moves are rejected.
- Keep one active name editor across the tree, including Favorites duplicates. Moving to another name, group or value cancels the previous unsubmitted name; Enter saves it.
- Use consistent Favorites labels, hover/focus row actions and reduced-motion-aware search transitions. Parameter units remain plain text; changing an individual parameter's unit/type is unavailable.

### Find References and cleanup

- Open Find References from a parameter row to inspect direct and indirect uses, grouped by owning sketch or timeline feature. Follow dependent user parameters with breadcrumb navigation, or select a verified owner in Fusion without moving the timeline marker.
- Dashed names mark user parameters with no verified dependents or saved variant uses. Unknown dependency data does not produce unused markers.
- The broom beside search opens an unused-user-parameter preview. Uncheck anything to keep it and its required inputs. Favorites, model dependencies and saved variant targets/formulas are protected.
- Cleanup requires explicit confirmation, a fresh document/entity/dependency snapshot and native deletion checks. The whole operation is one undoable transaction; a native refusal rolls it back. Unknown dependencies or invalid saved formulas block cleanup.

### Reliability

- Validate requests before ending an active native command, then recheck the document, entities and source data in a separate Paramood transaction. Invalid requests leave the command active; changed snapshots fail before writing. An ended native preview is discarded, while completed geometry remains.
- Keep assignment previews mounted through incomplete input and delayed checks. Outdated previews cannot enable Apply. Support a trailing semicolon in a batch.
- Preserve full group identity while filtering, inline editor focus, search scroll restoration, ordinary selections and existing variant transaction guards.

### Verification and limits

- Final local checks: 686 Python tests and 22 subtests, 306 frontend tests, 50 IntelliSense tests; Ruff, Prettier, ESLint, Python compilation, TypeScript/Vite and package checks passed. CI verifies Linux, macOS and Windows separately.
- Browser fixture acceptance covers search/focus/scroll, group drag and rename, reference navigation, stable previews and cleanup selection/confirmation. This is separate from native CAD acceptance.
- Native macOS Fusion 2706.1.17 acceptance covers Circle transaction durability, group rename/drag and Undo/Redo, reference selection, preview stability, cleanup selection/deletion/Undo/stale guards and rollback. The final name-editor follow-up passed real palette clicks in a new disposable model; all five pre-existing document parameter fingerprints and modified flags remained unchanged.
- Contract/security review checked escaped UI text, bridge request/document validation, entity membership, snapshot freshness, protected dependency closure and transactional failures. No new network transport or executable input was introduced. Production dependency audit: zero vulnerabilities; seven existing moderate findings remain in development tooling, which is absent from the ZIP.
- Native Windows, F3D/cloud save and reopen, cold restart, every interactive command state and exhaustive model consumers remain untested. A conservative cleanup preview can still meet a hidden native blocker; the complete delete then rolls back. Existing 2.x variant-storage and downstream-feature-error limitations remain.
