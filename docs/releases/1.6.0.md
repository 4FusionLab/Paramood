## Paramood 1.6.0

### Expression IntelliSense

- Complete all 26 documented Fusion functions and `PI`, `E`, `Gravity`, and `SpeedOfLight` from one typed metadata catalog shared with the Python planner.
- Show English descriptions, signatures, argument types, return dimensions, restrictions, and examples. Reuse existing parentheses and place the cursor inside the call.
- Add nested Signature Help with active-argument emphasis, cursor tracking, and a readable, scrolling tooltip in narrow Fusion palettes.
- Distinguish functions, constants, parameters, batch declarations, units, strings, numbers, operators, unknown names, and confirmed errors. Preserve parameter hierarchies, model dimensions, inline edits, and batch context after function argument separators.
- Diagnose unknown calls, wrong argument counts, simple dimension mismatches, commas, invalid operators, extra closing parentheses, and calling constants. Defer automatic native validation for incomplete calls and known identifier prefixes.
- Extend local evaluation with inverse/hyperbolic functions, logarithms, exponentials, powers, modulo, constants, time intermediates, comparisons, and logical conditions. Match Fusion's two-argument min/max, positive-only sign, and rounding halfway away from zero. Use native Fusion preferences for bare trigonometric arguments.
- Evaluate `random()` through native Quick Calculator. Reject random-dependent stable Preview/Apply explicitly; distinguish unsupported local evaluation from invalid expressions.
- Add the English [expression reference](https://github.com/4FusionLab/Paramood/blob/main/docs/EXPRESSION_REFERENCE.md) with functions, constants, units, shortcuts, and limitations.

### Validation and limits

Catalog-driven Python, IntelliSense, and CodeMirror integration tests accompany existing regressions. Ruff, Prettier, ESLint, TypeScript/Vite, deterministic ZIP, embedded catalog, and SHA-256 checks are required by CI.

Native macOS Fusion 2706.1.17: 29 catalog-example parameters created, 25 deterministic function results compared, 30 calculator calls, relative updates, dependencies, virtual paths, and stable-random rejection passed. A local F3D round trip preserved 31 parameters and a saved variant. The installed test ZIP's frontend was visually checked in a 361-pixel Fusion Palette: nested/active signatures, dark-theme contrast, completion insertion, actual Apply (`16`), and inline constant editing (`2 * PI`) passed. Original user documents were preserved.

Final batch quantities remain length, angle, unitless, or text. Other physical units and fractional dimensions remain explicit local-planner limitations. Dimension diagnostics intentionally cover only locally provable cases. Windows Fusion, light-theme native UI, cloud Save, and full add-in stop/restart were not tested; the previously reported restart crash is not claimed fixed. See the [acceptance record](https://github.com/4FusionLab/Paramood/blob/main/docs/EXPRESSION_ACCEPTANCE.md).
