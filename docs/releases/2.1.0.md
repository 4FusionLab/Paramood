## Paramood 2.1.0

[Русский](https://github.com/4FusionLab/Paramood/blob/v2.1.0/docs/releases/2.1.0.ru.md)

### Parameter organization

- Drag an editable parameter by its name into an existing virtual group. The drop preview shows the resulting native Fusion name; drop onto **Named parameters** to return to the root. Only the dragged parameter is renamed. Name collisions block the move, and Escape or dropping outside a group cancels it.
- Preserve the existing rename checks for document identity, entity token, expression and unit. Fusion dependencies and saved variant references follow the renamed parameter.
- Copy a full native parameter reference from the row's context menu, including references to read-only dimensions.

### Interface feedback

- Animate group expansion, parameter and favorite insertion/removal, new variant rows, menus, dialogs, confirmations and notifications. Hide the Featured section when empty.
- Briefly highlight changed parameter values and calculation results. Give the favorite star a short response to a change.
- Animate row and column reordering after a drop. Outline the complete target row or column, including the pinned variant-name cell and column values.
- Respect the system preference for reduced motion. Exiting rows and overlays become inert immediately; completion fallbacks prevent suspended animation events from leaving stale UI behind.

### Reliability

- Preserve accessible Fusion selections during parameter operations and handle selections that Fusion cannot expose.
- Preserve editor focus when copying references, dismiss notifications automatically, and refine contextual unit completion.
- Give each variant-table opening its own session. Discarded drafts cannot reappear during an exit animation, and delayed work from an old session cannot close or save a newer table.
- Reset parameter-list editing state when switching documents while preserving it during ordinary refreshes of the same document.

### Verification and boundaries

- Local: 529 Python tests and 22 subtests, 242 frontend tests and 49 IntelliSense tests; formatting, lint, TypeScript/Vite and package integrity checks passed before publication. CI checks the supported operating systems separately.
- Native macOS acceptance used Fusion 2706.1.17 and a disposable model: name-drag renaming with dependency updates, favorites, parameter creation/deletion, variant creation/save, row/column order round-trip, collision/stale-document guards, configured rename references and accessible selection restoration.
- Browser acceptance also covers interrupted animations, reduced motion, parameter move previews and cancellation, and overlay lifecycle regressions.
- After the pre-release fixes, browser checks confirmed rapid Discard/reopen and cancellation of a deferred cell Save; native Fusion confirmed that switching to another document clears an open rename field. Temporary models were closed and the original document's parameters and modified flag were verified unchanged.
- Dependency audit reports no production vulnerabilities. The development-only TypeScript ESLint chain has seven moderate findings from [GHSA-g3hv-75wg-m249](https://github.com/advisories/GHSA-g3hv-75wg-m249); its current compatible dependency range has no upstream fix. These lint tools are not included in the Fusion ZIP.
- Native Windows acceptance, every interactive Fusion command/preview state, cloud save/reopen and exhaustive geometry combinations remain unverified. Automated CI is not native Fusion acceptance.
- Existing 2.x variant-storage and downstream-feature-error limitations remain unchanged. Inspect the model and timeline after applying parameter or variant changes.
