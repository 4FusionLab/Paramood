## Paramood 1.3.0

[English](1.3.0.md)

Работайте с параметрами Fusion непосредственно из палитры, получая больше контекста и реже прерываясь.

- Просматривайте выражения параметров модели рядом с вычисленными значениями и распознавайте справочные размеры эскиза: они отображаются в скобках и недоступны для редактирования из палитры.
- Переименовывайте доступные для изменения пользовательские параметры и параметры модели нажатием на имя.
- Редактируйте значения с подсказками IntelliSense и создавайте связанный параметр, вводя новое имя или определение, например `height=25`.
- Решайте поддерживаемое уравнение с масштабированной переменной при редактировании: например, `-height/5=50` создаёт `height=-250` и связывает редактируемый параметр с `-height/5`.
- Обновляйте состояние параметров в фоне без сброса палитры при обычной навигации и редактировании.
- Используйте дополненные английский и русский README со скриншотами, примерами и обновлёнными проверками разработки.
- Запускайте согласованные проверки форматирования и линтеры Python, TypeScript, JavaScript и веб-файлов в CI.

### Установка

Скачайте `Paramood-1.3.0.zip`, распакуйте его и добавьте папку `Paramood` в Fusion через **Utilities → Scripts and Add-Ins → Add-Ins**. Включите **Run on Startup**, чтобы палитра открывалась автоматически. Для работы аддона Node.js не нужен.

### Область и проверка

Решение уравнений поддерживает один новый параметр, умноженный или разделённый на числовые значения либо существующие безразмерные параметры. Для создания и связывания параметров нужна транзакция Fusion; если Fusion не может её начать, завершите активную команду или редактирование эскиза. Автоматическая очистка неиспользуемых параметров не входит в выпуск.

Автономные тесты и проверки CI не заменяют интерактивную проверку в Fusion. На временных моделях Fusion через адаптер проверены решение уравнений, копирование текущего значения и переименование связанного параметра; полный сценарий обновлённой палитры и нативная работа в Windows не проверялись. Прилагаемые скриншоты показывают палитру Fusion на реальной модели.

Полное описание возможностей и примеры доступны в [README на русском языке](https://github.com/4FusionLab/Paramood/blob/main/README.ru.md).
