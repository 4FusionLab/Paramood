## Paramood 1.5.1

English | [Русский](1.5.1.ru.md)

### Changes

- Offer `dN` model dimensions in IntelliSense only for the exact current token `d` or `D`, on either side of an assignment. Hide them for other tokens, including `de`, `d1`, and numbers, while retaining ordinary parameter completion.
- Support `+=5`, `-=5`, `*=2`, and `/=2` in inline numeric parameter edits. Preserve the existing formula and its dependencies. Addition and subtraction interpret a bare number in the parameter's unit; multiplication and division use dimensionless numbers.
- Keep preview and snapshot validation before writing relative edits. Reject incomplete input, multiple assignments, and relative arithmetic on text parameters.
- Update English and Russian user guides.

### Validation and known issue

Offline validation: 269 Python tests plus 19 subtests, 122 frontend tests, and 13 IntelliSense core tests; Ruff, Prettier, ESLint, TypeScript/Vite, and ZIP validation.

Native adapter checks ran in a dedicated temporary model on macOS, Fusion 2706.1.17: all four relative operations, formula dependency preservation, dimensionless updates, and stale-snapshot rejection passed. Existing user documents were preserved. The new completion behavior is covered by editor integration tests, including automatic popup updates as `d` becomes `de` or `d1`; the installed Fusion palette and Windows were not retested for this patch.

A Fusion crash was reported after stopping and restarting Paramood. Its cause remains unconfirmed and this patch does not claim to fix it. Save your work before updating or restarting the add-in. Restart testing was not repeated with modified user documents open.
