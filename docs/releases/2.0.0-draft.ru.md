# Paramood 2.0.0 — исторический черновик примечаний

[English](2.0.0-draft.md)

Исторический черновик до публикации. Загрузки и актуальные примечания находятся на [странице релиза 2.0.0](https://github.com/4FusionLab/Paramood/releases/tag/v2.0.0).

## Общая таблица вариантов модели

- Выбирается единый набор редактируемых параметров и поддерживаемых фич timeline. Варианты — строки, выбранные элементы — столбцы. Общие счётчики и **Edit variants** находятся в шапке меню.
- Выражения редактируются с IntelliSense, `this`, относительными операциями и поддерживаемым синтаксисом новых параметров и уравнений. Новые CAD-параметры создаются только при **Save**.
- Галочка фичи означает **Enabled**, снятая галочка — **Suppressed**. До **Save** изменения остаются черновиком; **Cancel** отбрасывает их после подтверждения.
- Save проверяет все строки и применяет изменённый активный вариант; остальные сохраняются без переключения. Параметры вне набора остаются глобальными. Участники отмечены иконкой таблицы.
- Предусмотрено изменение порядка строк и столбцов. Перетаскивание строк и столбцов и сохранение порядка после повторного открытия проверены во Fusion на macOS.

## Совместимость

2.0 хранит собственные данные `variants.v2`. Старые записи `variants.v1` не читаются, не переносятся и не удаляются. Варианты 1.x необходимо создать заново в новой таблице. Реализация самостоятельная и не использует Autodesk Configuration API; полной функциональной эквивалентности Fusion Configurations нет. См. [порядок работы и ограничения](../VARIANTS_V2.ru.md).

## Оставшиеся проверки

На macOS проверочный ZIP зарегистрирован и запущен во Fusion 2706.1.17. Одноразовая копия F3D открыта повторно, три варианта применены, порядок строк и столбцов сохранился после перетаскивания, Save и повторного открытия. Это ограниченная проверка установленной палитры, а не полная приёмка. Нативная проверка Windows не завершена; см. [запись проверок](2.0.0-review-checklist.md).
