## Paramood 2.2.1

[Русский](https://github.com/4FusionLab/Paramood/blob/v2.2.1/docs/releases/2.2.1.ru.md)

- Direct designs show a **Direct modeling** notice with a **Switch To Parametric** button. Switching requires an explicit click and applies to the current design. After a temporary export design closes, Paramood automatically returns to the original design's parameters and draft.
- **Favorite parameters** now preserves nested groups. The tree shows starred parameters and their parent groups, with expansion independent of the main parameter list.

### Verification

- Browser checks covered the Direct notice, its button and draft restoration.
- On macOS in Fusion 2706.1.17, ExporTo exported a 14-body STEP through a temporary Direct design. Paramood refreshed the original parameter list without an error banner. The conversion button preserved the solid in a separate test design. A separate temporary model verified Favorites nesting, search and unstar behavior.
