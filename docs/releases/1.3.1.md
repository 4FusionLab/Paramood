## Paramood 1.3.1

- Preserve a parameter's units when creating a linked parameter from its current value. For example, an angle entered in degrees is created with a degree expression instead of exposing Fusion's internal radians.
- Display numeric angle expressions in the parameter's own unit when opening inline editing, including parameters whose existing expression is in radians.
- Update the English and Russian README with screenshots of the palette itself in two-column and compact layouts.

### Installation

Download `Paramood-1.3.1.zip` below, extract it, then add the `Paramood` folder under **Utilities → Scripts and Add-Ins → Add-Ins** in Fusion. Enable **Run on Startup** to open the add-in automatically. Node.js is not required to run it.

### Validation

On a temporary Fusion design, the adapter created a linked parameter from `60 deg` with unit `deg`, expression `60.0 deg`, and the same numeric angle. Offline checks and CI do not replace interactive Fusion validation: the complete updated palette flow and native Windows behavior have not been verified.

See the [English README](https://github.com/4FusionLab/Paramood/blob/main/README.md) or [README на русском](https://github.com/4FusionLab/Paramood/blob/main/README.ru.md) for features and limitations.
