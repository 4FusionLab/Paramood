# Paramood 1.0.0

[English](1.0.0.md) · [Русский README версии 1.0.0](https://github.com/4FusionLab/Paramood/blob/v1.0.0/README.ru.md)

Paramood добавляет в Autodesk Fusion компактный редактор параметров и калькулятор.

- Задавайте несколько параметров и просматривайте результат перед применением.
- Находите существующие и новые параметры с помощью иерархических подсказок: `box.size` соответствует `box_size`.
- Изменяйте существующие выражения с помощью `this`, `+=`, `-=`, `*=` и `/=`, сохраняя зависимости.
- Обновляйте данные модели при переключении документов или возвращении в редактор.

Скачайте `Paramood-1.0.0.zip`, распакуйте архив и добавьте содержащуюся в нём папку `Paramood` в Fusion через **Utilities → Scripts and Add-Ins**. При желании включите **Run on Startup**. Пакет поддерживает Windows и macOS; интерактивное тестирование в Fusion выполнено на macOS, но не на Windows.

Очистка в этот выпуск не входит. Поддержка выражений намеренно ограничена; неподдерживаемые формулы отклоняются. Перед применением изменений к модели проверьте предпросмотр.
