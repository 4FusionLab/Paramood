## Paramood 1.3.0

[Русская версия](1.3.0.ru.md)

Work with Fusion parameters directly from the palette, with more context and fewer interruptions.

- See model expressions alongside calculated values and identify driven sketch dimensions, which are displayed in parentheses and cannot be edited from the palette.
- Rename editable user and model parameters by clicking their names.
- Edit values with IntelliSense and create a linked parameter by entering a new name or a definition such as `height=25`.
- Solve a supported scaled-variable equation while editing, for example `-height/5=50`, which creates `height=-250` and links the edited parameter to `-height/5`.
- Refresh parameter state in the background without resetting the palette during normal navigation and edits.
- Use a more complete English and Russian README with screenshots, examples and updated development checks.
- Run consistent Python, TypeScript, JavaScript and web formatting and lint checks in CI.

### Installation

Download `Paramood-1.3.0.zip` below, extract it, then add the `Paramood` folder under **Utilities → Scripts and Add-Ins → Add-Ins** in Fusion. Enable **Run on Startup** to have the palette available automatically. Node.js is not required to run the add-in.

### Scope and validation

Equation solving supports one new parameter multiplied or divided by numeric values or existing dimensionless parameters. Creating and linking parameters requires a Fusion transaction; finish an active command or sketch edit if Fusion cannot start one. Automatic unused-parameter cleanup is not included.

Offline tests and CI checks do not replace interactive Fusion validation. Temporary Fusion designs were used to check equation solving, copying the current value and renaming a linked parameter through the adapter; the full updated palette workflow and native Windows behavior have not been validated. The supplied screenshots show the palette in Fusion on a real model.
