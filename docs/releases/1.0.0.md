# Paramood 1.0.0

[Русская версия](1.0.0.ru.md)

**English** · [Русский](https://github.com/4FusionLab/Paramood/blob/v1.0.0/README.ru.md)

Paramood brings a compact parameter editor and calculator into Autodesk Fusion.

- Define multiple parameters and preview results before applying changes.
- Find existing and newly declared parameters with hierarchical IntelliSense: `box.size` refers to `box_size`.
- Update existing expressions with `this`, `+=`, `-=`, `*=`, and `/=` while preserving dependencies.
- Refresh the model when switching documents or returning to the editor.

Download `Paramood-1.0.0.zip`, extract it, and add the contained `Paramood` folder through **Utilities → Scripts and Add-Ins** in Fusion. Enable **Run on Startup** if desired. The package supports Windows and macOS; native interactive testing has been performed on macOS, not on Windows.

Cleanup is not included in this release. Expression support is intentionally limited; unsupported formulas are rejected. Please review the preview before applying changes to a design.
