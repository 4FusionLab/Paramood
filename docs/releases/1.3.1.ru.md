## Paramood 1.3.1

[English](1.3.1.md)

- Сохраняются единицы параметра при создании связанного параметра из его текущего значения. Например, угол, введённый в градусах, создаётся с выражением в градусах, а не во внутренних радианах Fusion.
- При открытии встроенного редактирования числовые выражения углов показываются в собственных единицах параметра, в том числе если существующее выражение задано в радианах.
- Английский и русский README дополнены скриншотами палитры в двухколоночном и компактном режиме.

### Установка

Скачайте `Paramood-1.3.1.zip`, распакуйте его и добавьте папку `Paramood` в Fusion через **Utilities → Scripts and Add-Ins → Add-Ins**. Включите **Run on Startup** для автоматического запуска. Node.js для работы аддона не нужен.

### Проверка

На временной модели Fusion адаптер создал связанный параметр из `60 deg` с единицей `deg`, выражением `60.0 deg` и тем же числовым значением угла. Автономные проверки и CI не заменяют интерактивную проверку Fusion: полный сценарий обновлённой палитры и нативная работа в Windows не проверены.

Возможности и ограничения описаны в [английском](https://github.com/4FusionLab/Paramood/blob/main/README.md) и [русском README](https://github.com/4FusionLab/Paramood/blob/main/README.ru.md).
