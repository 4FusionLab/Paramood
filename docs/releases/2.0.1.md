## Paramood 2.0.1

[Русский](https://github.com/4FusionLab/Paramood/blob/v2.0.1/docs/releases/2.0.1.ru.md)

### Fixes

- Keep the native caret in the correct position when syntax highlighting changes token spans in Fusion, including typing `=` and deleting the final letter in `a.b`. Preserve backward selections, focus in other fields, and IME composition.
- Display numeric preview values without binary conversion noise: `3.0000000000000004 mm` becomes `3 mm`. Preserve source expressions, values used for Apply, small numbers, and text parameters.
- Suggest units after a numeric value or a completed parenthesized expression, including `10mm` and `1e-3 mm`. Hide unit suggestions in parameter names, at the start of expressions, after operators, and inside strings.
- Typing `=` after an assignment target ending in a dot replaces that final dot: `d.max.` becomes `d.max=`. Keep the caret after `=` and restore the original text with Undo. Do not intercept decimal points, right-hand expressions, or quoted text.

### Verification

- Offline: 511 Python tests and 22 subtests, 203 frontend tests, and 48 IntelliSense core tests; Ruff, Prettier, ESLint, TypeScript/Vite, and package build passed.
- Browser: 40 repeated typing/deletion checks passed for dotted Latin and Cyrillic names and `d.max=10`.
- Native macOS Fusion: reproduced and verified the caret fix for `a.b` deletion and `d.max=10`. Add-in startup and the palette connection were verified with one active copy.
- Preview formatting, contextual unit suggestions, and the trailing-dot shortcut have automated coverage; native acceptance for these additions and native Windows testing have not been performed. CI platform checks are separate from installed Fusion acceptance.
