## Paramood 1.5.0

English | [Русский](1.5.0.ru.md)

Save and switch model variants, edit text parameters, and work from the Hybrid palette without leaving your Autodesk Fusion design.

### Changes

- Save named variants of selected user, model, and text parameters, then apply them from the palette header. Variants travel with the Fusion design and F3D export.
- Edit a variant with the same parameter hierarchy as the main list. IntelliSense search can select and set an existing parameter with input such as `box.width=30`; **Save & apply** saves and applies the draft.
- Automatically update an active variant after successful Paramood edits, including newly changed members. **Free** keeps current model values and lets edits leave saved variants unchanged. External changes that no longer match leave the variant intact and switch to Free.
- Start in **Hybrid** view, with a scrollable parameter list and fixed input. Results, history, and previews open in a dismissible panel. Separate Calculator and Parameter list views preserve shared input.
- Change design length display units beside the model name without changing physical sizes. Synchronization is automatic; the general Refresh button has been removed.
- Create text parameters from single- or double-quoted literals. Preserve source formulas, references, concatenation, and supported conditional text while displaying computed text in the list.
- Copy calculator values with units using one result icon, or use **Copy expression**. Clipboard fallback reports actual failure and restores editor focus. Success notifications close after 3.5 seconds; errors remain dismissible.
- Include the Cedar & Sage F3D example with Classic, Compact, and Garden, plus English/Russian walkthroughs and real installed-Fusion screenshots.
- Accept Fusion's transitive dependency reports when checking the parameter graph, allowing valid edits in the feeder model without treating those API links as inconsistent direct dependencies.
- Keep a scalar parent value editable when the same row also expands grouped child parameters.
- Copy synchronously inside Fusion's Qt palette during the click gesture, avoiding a Clipboard API request that can remain pending.
- Enforce text-size limits across affected descendants as well as explicitly edited strings, preventing a limit bypass through dependent formulas.
- Update English and Russian guides for variants, text, units, and the palette workflow.

### Behavior and limitations

Variants store selected parameters rather than a complete model snapshot. Parameters outside a variant retain their current state. Removing a member or deleting a variant does not delete CAD parameters. On reopening, the first created variant whose member values match is selected; otherwise the palette shows Free.

Timeline errors and warnings do not roll back an applied variant. Inspect the geometry before saving or sharing it. Expression errors, stale requests, and incomplete writes are reported separately. Externally linked components and driven sketch dimensions are not edited.

Text parameters cannot change to numeric type or vice versa. Supported text grammar and escaping are documented in the user guide. A text result is limited to 65,536 characters and the projected text for a planned batch to 262,144 characters. Automatic unused-parameter cleanup remains unavailable.

### Installation

Download `Paramood-1.5.0.zip` from [Releases](https://github.com/4FusionLab/Paramood/releases), extract it, then add its `Paramood` folder under **Utilities → Scripts and Add-Ins → Add-Ins** in Fusion. Enable **Run on Startup**. Node.js is not required. When updating, stop and restart the add-in so its Python runtime and compiled palette both reload.
