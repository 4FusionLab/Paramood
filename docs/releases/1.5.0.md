## Paramood 1.5.0

Save and switch model variants, edit text parameters, and work from the Hybrid palette without leaving your Autodesk Fusion design.

### Changes

- Save named variants of selected user, model, and text parameters, then apply them from the palette header. Variants travel with the Fusion design and F3D export.
- Edit a variant with the same parameter hierarchy as the main list. IntelliSense search can select and set an existing parameter with input such as `box.width=30`; **Save & apply** saves and applies the draft.
- Automatically update an active variant after successful Paramood edits, including newly changed members. **Free** keeps current model values and lets edits leave saved variants unchanged. External changes that no longer match leave the variant intact and switch to Free.
- Start in **Hybrid** view, with a scrollable parameter list and fixed input. Results, history, and previews open in a dismissible panel. Separate Calculator and Parameter list views preserve shared input.
- Change design length display units beside the model name without changing physical sizes. Synchronization is automatic; the general Refresh button has been removed.
- Create text parameters from single- or double-quoted literals. Preserve source formulas, references, concatenation, and supported conditional text while displaying computed text in the list.
- Copy calculator values with units using one result icon, or use **Copy expression**. Clipboard fallback reports actual failure and restores editor focus. Success notifications close after 3.5 seconds; errors remain dismissible.
- Include the Cedar & Sage F3D example with Classic, Compact, and Garden, plus English/Russian walkthroughs and real installed-Fusion screenshots.
- Accept Fusion's transitive dependency reports when checking the parameter graph, allowing valid edits in the feeder model without treating those API links as inconsistent direct dependencies.
- Keep a scalar parent value editable when the same row also expands grouped child parameters.
- Copy synchronously inside Fusion's Qt palette during the click gesture, avoiding a Clipboard API request that can remain pending.
- Enforce text-size limits across affected descendants as well as explicitly edited strings, preventing a limit bypass through dependent formulas.
- Update English and Russian guides for variants, text, units, and the palette workflow.

### Behavior and limitations

Variants store selected parameters rather than a complete model snapshot. Parameters outside a variant retain their current state. Removing a member or deleting a variant does not delete CAD parameters. On reopening, the first created variant whose member values match is selected; otherwise the palette shows Free.

Timeline errors and warnings do not roll back an applied variant. Inspect the geometry before saving or sharing it. Expression errors, stale requests, and incomplete writes are reported separately. Externally linked components and driven sketch dimensions are not edited.

Text parameters cannot change to numeric type or vice versa. Supported text grammar and escaping are documented in the user guide. A text result is limited to 65,536 characters and the projected text for a planned batch to 262,144 characters. Automatic unused-parameter cleanup remains unavailable.

### Installation

Download `Paramood-1.5.0.zip` from [Releases](https://github.com/4FusionLab/Paramood/releases), extract it, then add its `Paramood` folder under **Utilities → Scripts and Add-Ins → Add-Ins** in Fusion. Enable **Run on Startup**. Node.js is not required. When updating, stop and restart the add-in so its Python runtime and compiled palette both reload.

### Изменения

- Именованные варианты пользовательских, модельных и строковых параметров переключаются в шапке, сохраняются с моделью и переносятся в F3D.
- Редактор использует общую иерархию и поиск с IntelliSense. Ввод `box.width=30` выбирает существующий параметр и меняет черновик; **Save & apply** сохраняет и применяет его.
- Успешные изменения через Paramood обновляют активный вариант и добавляют изменённые параметры. **Free** сохраняет текущие значения, отключая запись в вариант. Внешние несовпадающие изменения переводят в Free без перезаписи набора.
- По умолчанию открыт **Hybrid**: прокручиваемый список, закреплённый ввод и закрываемая панель результатов, истории и предпросмотра. Отдельные виды сохраняют общий ввод.
- Единицы отображения длины меняются рядом с названием модели без изменения физических размеров. Синхронизация автоматическая, общая кнопка Refresh удалена.
- Строки создаются литералами в одинарных или двойных кавычках. Вычисленный текст показывается в списке, исходные формулы и ссылки сохраняются для редактирования.
- Одна иконка копирует результат с единицами; **Copy expression** копирует выражение. Резервный путь буфера сообщает об отказе и восстанавливает фокус. Успех исчезает через 3,5 секунды, ошибки закрываются вручную.
- Добавлен F3D Cedar & Sage с Classic, Compact и Garden, инструкциями EN/RU и настоящими скриншотами установленного Fusion.
- Учтены транзитивные зависимости, возвращаемые Fusion API: допустимые правки модели не отклоняются из-за ошибочного сравнения с прямыми связями.
- Собственное значение родительской строки доступно для редактирования, даже если строка раскрывает дочерние параметры.
- Копирование внутри Qt-палитры выполняется синхронно во время клика, без зависающего запроса Clipboard API.
- Ограничение длины текста проверяется и для затронутых зависимых формул, предотвращая обход через дочерние строки.
- Обновлены руководства на русском и английском.

### Ограничения и проверка

Вариант содержит выбранные параметры, а не снимок всей модели; остальные параметры при переключении сохраняются. Удаление участника или варианта не удаляет CAD-параметры. При открытии выбирается первый созданный полностью совпавший вариант, иначе Free.

Ошибки и предупреждения timeline не откатывают применение. Перед сохранением и передачей проверяй геометрию. Типы текста и чисел не смешиваются; результат строки ограничен 65 536 символами, суммарный текст планируемого пакета — 262 144. Внешние компоненты, справочные размеры и автоматическая очистка не входят в доступные изменения.

Установленная палитра проверена на macOS в Fusion 2706.1.17 с Python 3.14.7. [F3D Cedar & Sage](https://github.com/4FusionLab/Paramood/blob/v1.5.0/examples/cedar-sage/Cedar-Sage-Paramood.f3d) экспортирован в исправном Classic и повторно открыт именно из этого файла. Разрешились все 24 участника вариантов. Через реальный UI применены Compact и Garden с ожидаемыми размерами и 14 исправными телами; затем восстановлен Classic. Настоящие скриншоты показывают родительские значения с дочерними параметрами, редактор варианта, строки и результаты Hybrid. Нативная проверка буфера подтвердила копирование и вставку `30.00 mm`; inline-редактор родительского значения применил `6`.

Предыдущие изолированные проверки Fusion покрывают создание строк, смешанные пакеты, ошибки типов, единицы, перенос F3D и ошибки timeline без отката. Независимое ревью исправлений не выявило блокирующих проблем. Offline-проверки пройдены: 269 Python-тестов и 19 subtests, 106 frontend-тестов, 13 тестов корневого IntelliSense. Нативная Windows-приёмка не завершена. Область применения и данные модели приведены в [README на русском](https://github.com/4FusionLab/Paramood/blob/v1.5.0/README.ru.md), [English README](https://github.com/4FusionLab/Paramood/blob/v1.5.0/README.md) и [model-info.json](https://github.com/4FusionLab/Paramood/blob/v1.5.0/examples/cedar-sage/model-info.json).
