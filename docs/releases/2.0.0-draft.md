**Review draft, not a release.** Publication requires the owner's personal review and explicit authorization. Owner review of the screenshots, final package approval and release authorization remain outstanding.

## Model-wide variant table

- Configure one shared set of editable parameters and supported timeline features. Variants are rows; configured items are columns. The menu header contains the shared counts and **Edit variants**.
- Edit expressions with IntelliSense, `this`, relative operations and supported new-parameter and equation syntax. New CAD parameters are created only on **Save**.
- A checked feature is **Enabled**, and an unchecked feature is **Suppressed**. Changes remain a draft until **Save**; **Cancel** discards them after confirmation.
- Save validates every row and applies the changed active variant; other rows are stored without switching. Outside-set parameters remain global. A table icon identifies controlled parameters.
- Row and column ordering is designed to be editable. Native Fusion drag gestures and saved-order round-trip have been checked on both axes on macOS.

## Compatibility

2.0 stores its own `variants.v2` data. It does not read, migrate or delete older `variants.v1` records. Recreate 1.x variants in the new table. This is an independent implementation and does not use Autodesk's Configuration API; it does not offer full Fusion Configurations parity. See [the workflow and limits](../VARIANTS_V2.md).
