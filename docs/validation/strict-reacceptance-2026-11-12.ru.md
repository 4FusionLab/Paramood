## Нативная приёмка Autodesk Fusion

Среда: macOS, Fusion `2706.1.17`. Использованы три собственных временных документа. Backend проверялся на исправленных исходниках; после последней frontend-правки анимации фокус и прокрутка повторно проверены с итоговым bundle в модели из 93 параметров.

**Настоящие действия в палитре/UI:**

- При открытом редакторе `baseline=50 mm` клавиши `5`, `2`, `3`, Enter оставляли запрос поиска `523`, отсутствие совпадений и отсутствие случайной записи. В финальной сборке readback сохранил `50 mm` и все 93 параметра.
- Фильтр по комментарию, совпадающему только с собственным значением группы, не исключал скрытых потомков из переименования и переноса. Имена, зависимые формулы и столбцы вариантов следовали за всей группой. Идентичность сущностей сохранялась.
- Переименование `tray_depth` в `tray_height` и переключение Favorite во время Circle сохранялись после запуска следующего Circle и настоящего Escape на холсте.
- Смешанный числовой/текстовый пакет через настоящую кнопку Apply во время Circle создавал `ui_new=25 mm`, `ui_half=12.5 mm`, менял `baseline=40 mm` и текст `caption='Verified'`. Следующий Circle, Escape на холсте и Finish Sketch сохраняли результаты и завершённую геометрию окружности.
- В итоговой модели из 93 параметров закрытие поиска, начатого внизу списка, визуально возвращало нижние строки. Нативное наблюдение визуальное; числовые измерения прокрутки выше относятся к браузеру.

**Настоящий backend/обработчик, вызванный из нативной Python console; это не полное UI-покрытие:**

- Неверная идентичность сущности, чужой document ID и некорректный payload отклонялись без завершения Circle.
- Удаление, Apply/Save/Free/Delete вариантов и смена единиц документа сохранялись после завершения Circle. Устаревший снимок единиц отклонялся без завершения команды; допустимый переход mm→cm сохранял внутренние значения и радиус окружности.
- Временное выражение preview откатывалось со `100 mm` на `50 mm` при завершении команды. Повторная проверка возвращала `CONFLICT` для связанного запроса Favorite до его записи.
- Искусственная ошибка сохранения метаданных вариантов при переименовании группы откатывала нативную транзакцию без частичных имён/метаданных. Перехватчик восстановлен.
- Переименование группы в `корпус`, настоящий Undo и Redo через меню Edit совместно меняли имена, формулы и столбцы вариантов. Обычный Apply сохранял выделение завершённой окружности.
- Устаревший запрос после переключения собственных документов возвращал `STALE_DOCUMENT`; предлагаемый параметр не появлялся ни в одном из них.

Временные наблюдатели передавали вызовы оригинальным обработчикам и восстановлены; ответы об успехе не подменялись. При настройке регистрация событий из MCP-скрипта не переживала его контекст, поэтому add-in перезапущен через настоящую Python console Fusion. Эта ошибка настройки не считается ни дефектом продукта, ни успешной проверкой.
