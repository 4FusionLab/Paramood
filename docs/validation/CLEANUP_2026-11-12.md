# Unused parameter cleanup — November 12, 2026

Implemented in the existing dirty checkout without commit, push or publication. Other tasks' changes were preserved.

## Behavior and safeguards

The broom beside tree search opens Paramood-Cleanup. Analyze is read-only; candidates include unused user-parameter chains and text parameters. Favorites, model-parameter dependencies and saved variant targets/formulas protect their full dependency closure. Unchecking a candidate also keeps its required inputs. Search does not change the selection. Delete selected opens an explicit confirmation.

The native equation graph must be complete and coherent in both directions, including expression references. Unresolved variant targets, invalid saved expressions and unknown native blockers without exposed parameter dependents block or protect cleanup. Internal chain nodes may initially have isDeletable=false because user parameters depend on them. They are checked again after those dependents are deleted; any remaining native blocker aborts the entire command transaction. Consequently, the preview is a conservative candidate list, not a guarantee that every candidate will be deletable in every model.

The opaque preview is bound to the document, all parameter identities, expressions, units, user comments/favorites/deletability, dependencies and saved variant data. Saved entity tokens are resolved and compared to live entities, rather than comparing token strings. A changed snapshot is rejected. Retained candidates become graph roots again on the backend, so a forged client selection cannot delete their dependencies. Every delete checks native isDeletable, the deleteMe result, object validity and actual absence from allParameters. The existing independent Paramood command runs the operation; direct writes are prohibited. Read-only preflight occurs before ending any active native command, and execute revalidates before writing. Structured failures set executeFailed and abort the transaction.

Official sources were checked, with Context7 consulted for Fusion dependency and deletion APIs:

- [UserParameter.isDeletable](https://help.autodesk.com/cloudhelp/ENU/Fusion-360-API/files/fusion_UserParameter_isDeletable.htm)
- [UserParameter.dependentParameters](https://help.autodesk.com/cloudhelp/ENU/Fusion-360-API/files/fusion_UserParameter_dependentParameters.htm)
- [UserParameter.deleteMe](https://help.autodesk.com/cloudhelp/ENU/Fusion-360-API/files/fusion_UserParameter_deleteMe.htm): Autodesk documents a misleading true return on refusal; actual deletion is verified independently.
- [CommandEventArgs.executeFailed](https://help.autodesk.com/cloudhelp/ENU/Fusion-360-API/files/core_CommandEventArgs_executeFailed.htm)
