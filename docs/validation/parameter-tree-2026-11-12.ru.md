# Проверка дерева параметров — 12 ноября 2026

[English](parameter-tree-2026-11-12.md)

## Реализованная область

Поиск по native/виртуальному имени, выражению и комментарию с Unicode без учёта регистра,
контекстом предков, пустым результатом, независимым раскрытием поиска и восстановлением прокрутки.
Термин Favorites и удаление по hover/focus сохраняют существующие bridge и правила удаления.
Единицы — обычный текст без управления сменой, действий по нажатию или дисклеймеров; изменение единиц,
пересоздание параметра, вывод о разрешении по зависимостям и подмена единицами документа не добавлены.
См. [матрицу единиц](../PARAMETER_UNITS.ru.md).

## Offline

- Frontend: 270 тестов прошли, включая восемь новых регрессий поиска, Unicode,
  значений предков, восстановления, действий строки, неинтерактивных единиц, свёрнутого поиска и взаимодействия
  завершённого переноса, ручного сворачивания группы и очистки поиска.
- Финальный совместный прогон после отдельного фикса Circle: Python **560 + 22 subtests**;
  корневые JavaScript **50**; frontend **270** (15 файлов) — все прошли.
- Prettier, ESLint, Ruff format/lint и TypeScript/Vite build прошли.
- Локальный ZIP с явно заданной версией 2.1.0 собран только для проверки пакета;
  этот чат не создавал тег, коммит, push или релиз.
- Проверка контрактов/безопасности: поиск выводит экранированный Preact текст, не добавляет
  исполняемый ввод или bridge actions. Delete/favorite/rename и проверки документа остаются
  ответственностью backend. Расчёт drag использует полный snapshot, даже при фильтре дерева.

## Браузер — fixture bridge, не native acceptance

Playwright Chromium, 360×680 и 960×720, обычные анимации:

- Проверены комментарий с кириллицей, полный dotted path, выражение и отсутствие совпадений.
- Inline editor остаётся доступен, поиск сохраняет фокус при фильтрации редактируемой строки.
- Favorite action передаёт native имя, entity token, ожидаемое состояние и document ID.
- Delete opacity достигает 0 вне строки и 1 при hover/focus. Положение и ширина значения не меняются.
- Очистка возвращает прокрутку палитры 500 px (также 1544 px внизу списка с открытым Favorites) и независимое свёрнутое состояние групп.
- У единиц нет кнопок, переключателей или раскрываемых пояснений. Поиск по умолчанию свёрнут, открывается лупой с фокусом в поле и закрывается Escape/X с возвратом фокуса и дерева.
- Макеты проверены визуально. Единственная ошибка консоли — favicon, отсутствующий на dev-сервере.

## Fusion

Установленный Fusion 2706.1.17 на macOS: read-only проверка подтвердила отсутствие сеттеров
`UserParameter.unit.fset` и `UserParameter.valueType.fset`. У UserParameter нет методов смены
единиц/типа. Это подтвердило ограничение API перед проверкой палитры.
Затем на временных моделях проверены:

- Создание со всеми 96 именованными единицами существующего каталога, плюс Text и
  безразмерный параметр. Все созданы; Fusion нормализует написание некоторых единиц.
- `1 in` у параметра в mm и `1 rad` у параметра в deg сохраняют назначенные единицы.
  Физические значения, зависимая формула, разрешение исходного entity token, комментарий
  и избранное сохранились. Новые назначенные единицы по-прежнему недоступны.
- Установленная палитра до финального уточнения свёрнутого поиска, настоящий native bridge, тёмная тема: поиск по русскому комментарию,
  контекст групп, inline edit 20→25 mm, перенос найденного `box_inner_depth` в `tray` за имя,
  Favorites, пустой поиск и восстановление через Escape. Native readback подтвердил
  `tray_depth = box_width / 2`, значение 12.5 mm и сохранение комментария.
- Обе собственные временные модели закрыты без сохранения; восстановлены прежний документ,
  fingerprint параметров и состояние modified.

Отдельное [расследование Circle](circle-parameter-transactions.ru.md) воспроизвело и устранило
откат параметров внутри native команды. Его runtime изменения вошли в финальные совместные
проверки выше. Эта native приёмка выполнена отдельным чатом.

Windows native не проверен.

## Последующее уточнение

Пользователь попросил сворачивать поиск по умолчанию и полностью убрать возможность и подсказки
смены единиц/типа. Изменения внесены и покрыты финальными 270 frontend тестами и браузерной проверкой.
Обновлённая native палитра визуально показывает свёрнутый поиск и обычный текст единиц.
Открытие/закрытие и фокус для этого уточнения проверены в браузерном fixture; предыдущая native
приёмка редактирования/drag/Favorites записана выше. Format, lint, build и локальный пакет прошли.
При этом уточнении модели не изменялись.
